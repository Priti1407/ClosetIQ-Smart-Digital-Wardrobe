# ClosetIQ — Smart Digital Wardrobe

A responsive wardrobe organizer and outfit-planning web app built with HTML, CSS, and vanilla JavaScript.

## Features
- Add clothing pieces with a name, category, color, notes, and optional image URL.
- Browse, search, filter, sort, and remove wardrobe items.
- Create outfits by selecting pieces from your own closet, then save and reload looks.
- Plan upcoming outfits by date and occasion.
- Dashboard statistics update as your wardrobe changes.
- Uses browser Local Storage so your wardrobe, saved outfits, and plans persist on the same browser/device.
- Responsive layout for desktop, tablet, and mobile.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a modern browser. No build tools are required.
3. Add, edit, and organize your own wardrobe items.

## Notes
- The starter closet is pre-populated with sample pieces so the interface is useful on first launch. Remove them and add your own items whenever you like.
- Sample photos load from Unsplash and require an internet connection. You can add your own public image URLs or leave the image field blank.
- Data is stored in local browser storage, not a cloud database. It does not automatically sync across devices or browsers.
